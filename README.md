## Project Overview

This project explains important cybersecurity concepts in simple language for non-technical users. It focuses on safe internet usage, especially when connecting to public Wi-Fi networks.

## Topics Covered

* **DNS:** How domain names are translated into IP addresses.
* **HTTPS/TLS:** How secure connections help protect information exchanged between a browser and a website.
* **VPNs:** How a Virtual Private Network can protect traffic between a device and a VPN server.
* **Public Wi-Fi Risks:** Fake hotspots, phishing, unsafe downloads, and privacy risks.
* **Firewalls:** How network traffic is filtered using security rules.
* **Captive Portals:** How to identify suspicious Wi-Fi sign-in pages.

## Safety Recommendations

* Verify the Wi-Fi network name with the venue's staff.
* Prefer HTTPS websites and do not ignore browser security warnings.
* Avoid entering banking details, PINs, or OTPs into suspicious Wi-Fi portals.
* Use a trusted VPN when appropriate.
* Keep your device and applications updated.
* Disable automatic connection to unknown Wi-Fi networks.
* Disconnect and report suspicious networks or login pages.

## Methodology

The project uses cybersecurity awareness research and trusted educational references to explain common network security concepts and practical safety measures. No unauthorized network testing was performed.
